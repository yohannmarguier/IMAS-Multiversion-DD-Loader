## Stage samples

Per-sample stage timestamps (connection setup, complete query retrieval, decoding, scope validation, rule construction, map validation and publication) are retained in the companion JSON evidence. `Connection` records construction of the configured Bolt driver; the driver may establish its TCP session lazily with the first query, so transport handshake time is included in query retrieval rather than overstated as an eagerly verified connection time. Timed-out rows retain the terminal failure and their stage timestamps but have no retained-map or lookup figures, because failed maps are never published or cached.
